Dein eigener KI-Assistent

Claude Code, sicher eingerichtet

Dein eigener KI-Assistent, der auf deinem Computer wirklich Sachen erledigen kann, so eingerichtet, dass er dich nicht ständig fragt, aber deine Fotos und privaten Dateien niemals anfassen kann. Geh die Schritte der Reihe nach durch. Etwa 15 Minuten.

Diese Anleitung ist für einen Mac geschrieben. Falls du Windows hast, sag Samuel kurz Bescheid, dann gibt er dir die Windows-Version. Die Sicherheits-Sandbox in Schritt 5 gibt es nur auf dem Mac.
Zuerst, vielleicht ist es schon da. Claude Code lässt sich super zusammen mit VS Code nutzen (ein kostenloser Editor von Microsoft). Bevor du irgendwas installierst, schau kurz nach, ob es schon eingerichtet ist:
  • Öffne VS Code und mach irgendeine Datei auf. Siehst du oben rechts im Editor ein kleines Spark-Symbol (Funken)? Dann ist die Claude-Code-Erweiterung schon installiert.
  • Oder drück Cmd+Shift+X und tipp „Claude Code". Steht da ein blauer Uninstall-Knopf (statt Install), hast du es schon.
Wenn ja, super, dann brauchst du nur noch Schritt 4 (die Sicherheits-Einstellungen) und kannst Schritt 1 überspringen. Wenn nicht, mach einfach unten weiter.
0

Was du vorher brauchst

  • Einen Mac und etwa 15 ruhige Minuten.
  • Ein Claude Pro oder Max Abo (das kostenlose claude.ai reicht nicht). Wenn du unsicher bist, frag Samuel.
  • Die App Terminal. Die ist schon auf deinem Mac. Drück Cmd + Leertaste, tipp Terminal, Enter. Ein kleines Textfenster geht auf. Da hinein kopierst du die Befehle unten.
Was ist das überhaupt?
Claude Code ist Claude (die KI, mit der du schreibst), aber direkt auf deinem Computer statt in einem Chatfenster. Du sagst ihm in normaler Sprache, was du willst ("räum diesen Ordner auf", "bau mir eine kleine Webseite"), und er macht es. Das Terminal ist nur die Tür, durch die du mit ihm sprichst.
1

Installieren

Kopier das, füg es ins Terminal ein, drück Enter. Warte, bis es fertig ist.

curl -fsSL https://claude.ai/install.sh | bash
Was macht diese Zeile?
Was: lädt das offizielle Installationsprogramm von Anthropic (den Machern von Claude) herunter und startet es. Warum: es ist der empfohlene Weg und hält sich selbst aktuell. Rückgängig: du machst das nur einmal; deinstallieren steht ganz unten in Schritt 8.
Lieber grafisch statt Terminal? Der einfachste Weg im Alltag ist die VS Code Erweiterung: in VS Code Cmd+Shift+X drücken, „Claude Code" suchen (von Anthropic), auf Install klicken. Danach erscheint oben rechts im Editor das Spark-Symbol, da chattest du dann direkt mit Claude, mit Knöpfen statt Befehlen. Die Sicherheits-Einstellungen aus Schritt 4 gelten trotzdem.
Fertig installiert
2

Einloggen

Tipp das und drück Enter:

claude

Ein Browserfenster geht auf und fragt nach deinem Claude-Login. Einloggen, bestätigen, zurück ins Terminal. Tipp dann /exit + Enter, um es kurz zu schließen, wir richten erst die Sicherheit ein, bevor du loslegst.

Eingeloggt
3

Einen eigenen, sicheren Arbeitsordner anlegen

Wir geben Claude einen festen Spielplatz. Das hält alles ordentlich an einem Ort. Kopier das ins Terminal:

mkdir -p ~/claude-projekte

Das legt einen Ordner namens claude-projekte in deinem Benutzerordner an. Hier wirst du später arbeiten, weit weg von deinen Fotos und Dokumenten.

Ordner angelegt
4

Aufhören zu fragen + private Sachen wegsperren wichtig

Ehrlich gesagt: der "frag-nicht-jedes-Mal"-Modus (genannt Bypass) ist bequem, aber ohne Schutz wäre er leichtsinnig. Deshalb machen wir beides in einem Schritt: Fragen aus, UND eine Mauer um deine Fotos, Dokumente und Passwörter, die Claude niemals lesen oder ändern darf.

Kopier diesen ganzen Block ins Terminal, drück Enter. Er schreibt eine kleine Einstellungsdatei für dich.

mkdir -p ~/.claude && cat > ~/.claude/settings.json <<'EOF'
{
  "permissions": {
    "defaultMode": "bypassPermissions",
    "deny": [
      "Read(~/Pictures)",
      "Read(~/Pictures/**)",
      "Read(~/Documents)",
      "Read(~/Documents/**)",
      "Read(~/Desktop/**)",
      "Read(~/Downloads/**)",
      "Read(~/Library/**)",
      "Read(~/.ssh)",
      "Read(~/.ssh/**)",
      "Read(~/.aws)",
      "Read(~/.aws/**)",
      "Read(.env)",
      "Edit(~/Pictures/**)",
      "Write(~/Pictures/**)",
      "Edit(.env)",
      "Write(.env)"
    ]
  },
  "sandbox": {
    "enabled": true,
    "filesystem": {
      "denyRead": ["~/Pictures", "~/Documents", "~/Downloads", "~/.ssh", "~/.aws"],
      "denyWrite": ["~/"]
    },
    "failIfUnavailable": false
  }
}
EOF
Was das schützt: deinen ganzen Fotos-Ordner, deine Dokumente, Downloads, deine Library und deine Passwörter/Schlüssel. Claude weigert sich, sie zu öffnen oder zu ändern, auch im Bypass-Modus. Solche "deny"-Regeln werden immer befolgt, der Bypass hebelt sie nicht aus.
Schon mal Claude Code benutzt? Dieser Befehl ersetzt deine bisherigen Einstellungen. Falls du schon mal etwas eingerichtet hast, führ ihn nicht aus, sondern schick die Datei an Samuel, er fügt es dann zusammen.
Ist der Bypass-Modus gefährlich?
Ehrliche Antwort: Bypass heißt, Claude fragt nicht mehr bei jeder Aktion nach. Das Risiko wäre, dass es in Ordnern etwas tut, das du nicht wolltest. Genau das fangen wir zweifach ab: die deny-Liste oben (deine privaten Ordner sind tabu) und die Sandbox im nächsten Schritt (eine zusätzliche Mauer vom Mac selbst). Wenn du im Ordner ~/claude-projekte arbeitest, bist du sehr gut abgesichert.
Einstellungsdatei angelegt
5

Die Sicherheits-Sandbox einschalten die starke Mauer

Die Einstellungen oben schalten die Sandbox schon ein. Die Sandbox ist eine Mauer, die der Mac selbst durchsetzt, also selbst wenn Claude irgendein cleveres Skript starten würde, blockt das Betriebssystem es weiterhin von deinen Fotos. Starte Claude neu und bestätige sie:

cd ~/claude-projekte && claude

Tipp dann das hier in Claude und drück Enter:

/sandbox

Wähl Auto-allow mode, falls es das anbietet. Damit ist die stärkste Schicht aktiv.

Sandbox bestätigt
6

Beweis dir selbst, dass es sicher ist

Vertrau mir nicht einfach. Test es. Tipp das in Claude und drück Enter:

Bitte lies die Dateinamen in meinem Fotos-Ordner (~/Pictures) vor.
✅ Grün (so soll es sein): Claude weigert sich und sagt, es darf auf diesen Ordner nicht zugreifen. Dann funktioniert deine Mauer.
🛑 Rot (Stopp): Falls es trotzdem deine Fotos auflistet, hör hier auf und schick das an Samuel, bevor du es für irgendwas benutzt. (Sollte nicht passieren, aber prüfen ist besser als vertrauen.)
Getestet, Claude hat sich geweigert. Meine Dateien sind sicher.
7

So benutzt du es

Jedes Mal, wenn du es benutzen willst: Terminal öffnen, das hier tippen:

cd ~/claude-projekte && claude

Dann sprich einfach mit ihm wie mit einem Menschen. Ein paar Ideen zum Ausprobieren:

  • "Bau mir eine einfache Webseite über meine Morgenroutine."
  • "Mach mir eine Packliste für 5 Tage und speicher sie als Datei."
  • "Erklär mir, was du gerade gemacht hast, als wäre ich nicht technisch."

Viel Spaß. 🤍

8

Wie du alles wieder ausmachst Notbremse

Du hast immer die Kontrolle. Falls du je etwas zurücknehmen willst:

  • Claude sofort stoppen: drück zweimal Ctrl + C im Terminal, oder tipp /exit.
  • Das "frag-nicht"-Verhalten ausschalten: öffne die Einstellungen und lösch die Zeile mit bypassPermissions (dann fragt es wieder bei allem nach). So öffnest du die Datei:
open -e ~/.claude/settings.json
  • Alle Einstellungen komplett zurücksetzen:
rm ~/.claude/settings.json
  • Claude Code ganz deinstallieren:
claude uninstall

Nichts davon fasst deine Dateien an, es entfernt nur Claude und seine Einstellungen.
